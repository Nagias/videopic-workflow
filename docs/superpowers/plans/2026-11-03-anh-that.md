# Ảnh thật cho sản phẩm và bối cảnh — kế hoạch làm

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cho tải ảnh thật vào node Đồ vật (từng trạng thái) và Hồ sơ không gian; Biên kịch và từng thẻ Cảnh dùng đúng sản phẩm thật đó.

**Architecture:** Một endpoint nhận file ảnh, ghi qua `storage.importFile`. Tham số node lưu mã ảnh (`photos`). Node Đồ vật/Không gian dùng ảnh thật thay cho bước Muse; trạng thái thiếu ảnh thì Muse vẽ có đính kèm ảnh thật. Sản phẩm đi vào Biên kịch và mọi thẻ Cảnh qua một cổng mới tên `product` (kiểu `props`), gộp với đồ phụ trước khi kiểm luật và chọn ảnh đính kèm.

**Tech Stack:** TypeScript, Fastify 5, React + xyflow, zod, Vitest, Playwright, ffmpeg/ffprobe.

**Spec:** `docs/superpowers/specs/2026-11-03-anh-that-design.md`

## Global Constraints

- Ảnh nhận: `image/jpeg`, `image/png`, `image/webp`; tối đa **20 MB** (`20 * 1024 * 1024`). Lưu nguyên định dạng gốc, **không** cắt về 16:9, không đổi định dạng.
- Mọi lỗi người dùng thấy viết tiếng Việt. HEIC: đúng câu `Ảnh HEIC chưa đọc được, hãy lưu lại thành JPG`.
- Giao diện gọi máy chủ chỉ qua `src/app/api-client.ts`; file media chỉ ghi qua `storage.importFile`; mọi prompt Muse ở `src/shared/prompts.ts`.
- Prompt và khoá bước con của cảnh/đồ vật **không có sản phẩm, không có ảnh thật** phải giữ **nguyên từng ký tự** (cache cũ phải trúng). Mỗi task có thay đổi khoá/prompt phải có test chứng minh điều này.
- Không đổi cổng `props` cũ của node Cảnh; không sửa node `film` (đã ẩn).
- Không có luật về số cảnh/thời lượng sản phẩm xuất hiện.
- Endpoint và `data-testid` mới ghi vào `FEATURE_MAP.md` (test kiến trúc kiểm).
- Commit tiếng Việt `<vùng>: <mô tả>`, kết thúc bằng dòng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Hook commit chạy `npm run verify` (~5 phút).
